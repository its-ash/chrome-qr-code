QR CODE

Generate a QR code for the current page or any custom text instantly. Minimal, local, and fast.

Download ZIP Download CRX

Features

  • Auto-generate a QR for the active tab when you open the extension.

  • Editable input field. Change the text or URL and the QR updates live.

  • Copy the QR image to the clipboard or download it as a PNG.

  • Generates QR codes locally. No external servers.

The ZIP contains the built extension files, ready to use as an unpacked extension. If you have a .crx file, place it alongside this page before building and the CRX link will work.
