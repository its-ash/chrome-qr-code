A QR code for every tab.

Open the popup and your page is ready to scan. Style it, then save it as PNG or SVG.

Download View source

Small popup, full control

Everything happens in one window that opens from your toolbar.

Make it yours

Pick a color, error correction level, and export size. Your choices are kept for next time.

Ready on open

The address of the current tab fills in by itself. Type to replace it with any text.

Copy in one click

Put the image on your clipboard, then paste it into a doc, chat, or slide.

PNG or SVG

Sharp PNG files up to 2048 px, or a vector SVG for print.

Light and dark

The popup follows your system theme. The code stays dark on light, so every phone camera can read it.

Your links never leave your device.

Every code is drawn inside the popup. There is no account, no analytics, and no server.

One permission
activeTab, used only when you open the popup.
No network calls
The QR code is made in your browser, so it works offline.
Local settings
Your style choices stay in the popup's local storage.

Install in a minute

Load the extension in Chrome or any Chromium browser, such as Edge, Brave, or Arc.

Download
  1. Unzip the downloadYou get a folder named dist.
  2. Open chrome://extensionsTurn on Developer mode in the top-right corner.
  3. Select Load unpackedChoose the dist folder, then pin QR CODE to your toolbar.
